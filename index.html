AnimeeDonghua Studio

A private desktop tool for the YouTube channel Anime & Donghua (@animeedonghua).

AnimeeDonghua Studio is a Windows app that the channel owner runs on their own computer. It cuts short vertical clips from anime and donghua episodes and helps publish them as YouTube Shorts.

With the owner's permission, the app uses the YouTube Data API and the YouTube Analytics API to:

  • upload the owner's Shorts to the owner's channel, first as private videos;
  • set titles, descriptions, tags and publish times;
  • delete a video that fails YouTube's checks;
  • read view statistics, so the owner can see which Shorts work.

The app works only with the owner's own channel. It is not offered to the public, and it does not access anyone else's account.
